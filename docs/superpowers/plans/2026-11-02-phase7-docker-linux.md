# constlit Phase 7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `docker::port!` (`PortMapping`), `linux::errno!` (`Errno`, numbered per target), `linux::ifname!` and `linux::dev!` (`DevNum`).

**Architecture:**
- This follows phases 4 to 6:
  - a pure parser module per macro in `constlit-macros`;
  - prefixed proc macros (`docker_port`, `linux_errno`, `linux_ifname`, `linux_dev`), re-exported from `constlit::docker` and `constlit::linux`;
  - oracles wherever an authority exists.
- `errno!` works like `unix::signal!`:
  - The proc macro knows the names and which families have each one. It emits `cfg`-gated `compile_error!`s and a named const that reads a per-target table in the runtime crate.
  - The tables are generated from the `libc` crate's source.

**Tech Stack:**
- As in phase 6.
- The oracle gains `github.com/docker/go-connections` v0.8.2.
- The rustup target `powerpc64le-unknown-linux-gnu` is added, for the errno cross-check only.

**Spec:** `docs/superpowers/specs/2026-11-02-constlit-0.3-design.md`, Phase 7.

**Starting point:** `main` at `817d5c2`.
- The pattern to copy for `errno!` is `constlit-macros/src/signal.rs` (`families()`, `presence()`, `expand_signal`) together with `constlit/src/unix/signal.rs` (tables, `table` module).
- The oracle is `constlit-macros/oracle/main.go`, which has a per-subcommand header switch.

## Decisions this plan makes (my calls, within the spec)

- **`port!` strictness beyond `nat.ParsePortSpec`.** These were probed while writing the plan, and each is an error with a suggestion:

  | input | Go | ours |
  |---|---|---|
  | `"8080:80/TCP"` | ok (lower-cased) | `protocols are lower case: "8080:80/tcp"` |
  | `"::1:8080:80"` | ok | `put an IPv6 address in brackets: "[::1]:8080:80"` |
  | `"0:80"`, `"80:0"` | ok | `port 0 isn't a port; leave the host port out for any free port: "80"` (for a host port of 0), `port 0 isn't a port` (for a container port of 0) |
  | `"080:80"` | ok | `write the port without leading zeros: "80:80"` |
  | `"+80"` | ok | `write the port as plain digits: "80"` |
  | `"8080:80/"` | ok | `missing protocol after "/"; remove the "/" or write e.g. "8080:80/udp"` |
  | `":80"` | ok | `remove the empty host port: "80"` |

  The oracle test allows each of these only when the input matches the class.
- **`PortMapping` keeps ranges.** Go expands an equal-length range into one mapping per port, and keeps a host range with a single container port as one mapping. The oracle test expands our value the same way before comparing.
- **The errno tables are generated by `constlit-macros/oracle/errno_tables.py`,** a script kept in the repository and run once.
  - It reads `libc-0.2.191/src/unix/linux_like/linux_l4re_shared.rs` plus the family's architecture file:
    - generic: `linux/gnu/b64/x86_64/mod.rs`;
    - powerpc: `linux/gnu/b64/powerpc64/mod.rs`;
    - mips: `linux/gnu/b32/mips/mod.rs`;
    - sparc: `linux/gnu/b64/sparc64/mod.rs`.
  - It keeps `pub const E…: c_int = N;` with values 1-200, decimal or hex, and drops names starting `EPOLL`, `EFD_` or `EXT`, and `EOF`.
  - It prints the Rust arrays that go into `constlit/src/linux/errno.rs`, and the name list and per-family presence that go into `constlit-macros/src/errno.rs`.
  - The static asserts against `libc` are what verify the tables.
- **The canonical name of a number** is the first name in libc's order, excluding the aliases `EWOULDBLOCK`, `ENOTSUP` and (where it equals `EDEADLK`) `EDEADLOCK`. Aliases display canonically.

## Review Focus

1. **Ranges.**
   - `"8000-8010:8000-8010"` keeps both ranges and expands to 11 Go mappings.
   - `"8000-8010:80"` is a host range with a single container port.
   - `"8000:80-90"` is an error.
   - Pinned by `port_values` and the oracle (Task 1).
2. **IPv6 host addresses.** `"[::1]:8080:80"` gives `host_ip() == Some(IpAddr::V6(..))`. Pinned by `port_values` (Task 1).
3. **errno aliases.**
   - `errno!("EWOULDBLOCK") == errno!("EAGAIN")`, displaying as `EAGAIN`.
   - On powerpc, sparc and mips, `EDEADLOCK` is its own number and name.
   - Pinned by `errno_values` and the static asserts (Task 2).
4. **errno in non-`const` contexts and on unsupported targets.**
   - A `let` binding works.
   - `cargo check` for `aarch64-apple-darwin` fails with `errno! supports Linux and Android`.
   - Pinned by the scratch-crate check (Task 2).
5. **`dev!` limits and encoding.**
   - `"4095:1048575"` is valid; `"4096:0"` is an error.
   - `to_dev_t()` equals `libc::makedev` across the range.
   - Pinned by `dev_values` (Task 3).

- Test: unit tests, `constlit/tests/docker.rs`, and the UI tests `constlit/tests/ui/port_upper_proto.rs` and `port_zero.rs`.

**Interfaces:**
- Produces:
  - `constlit_macros::docker_port::parse_port(s: &str) -> Result<Port, String>`;
  - `pub struct Port { pub host_ip: Option<std::net::IpAddr>, pub host: Option<(u16, u16)>, pub container: (u16, u16), pub protocol: &'static str }`.
- Produces `constlit::docker`:
  - `Protocol { Tcp, Udp, Sctp }`, with `name()`;
  - `PortRange`, private `{ start, end }`, with `start()`, `end()` and `len()`, and `Display` writing `80` or `8000-8010`;
  - `PortMapping`, private, with `host_ip() -> Option<IpAddr>`, `host() -> Option<PortRange>`, `container() -> PortRange` and `protocol() -> Protocol`;
  - `Display` writes the canonical form: `[ip:]` (IPv6 in brackets), then `host:` if any (or `:` when there is an IP but no host port), then the container ports, then `/proto`.
  - Derives `Clone`, `Copy`, `Debug`, `PartialEq`, `Eq` and `Hash`.
- `port!` expands to `::constlit::docker::PortMapping::__new_unchecked(...)`, building the IP with `::core::net::IpAddr::V4(::core::net::Ipv4Addr::new(..))`, or `V6` likewise.

**Error messages (exact, beyond the strictness table above):**

|---|---|

| `"8080:80/icmp"` | `unknown protocol "icmp"; use tcp, udp or sctp` |
| `"65536:80"` | `port 65536 is out of range (1-65535)` |
| `"90-80:90-80"` | `the range 90-80 ends before it starts; write "80-90"` |
| `"8080:"` | `missing container port after ":"` |
| `"localhost:8080:80"`, `"a:b:c:d"` | `"localhost" is not an IP address; port mappings take an IP, like "127.0.0.1"` |
| `"8080 :80"` | `remove the spaces: "8080:80"` |
| `"80x"` | ``port `80x` is not a number`` |

### Task 2: `Errno` and `linux::errno!`

**Interfaces:**
- Produces:
  - `constlit_macros::errno::parse_errno(s: &str) -> Result<&'static str, String>`, returning the canonical name with its `E`;
  - `expand_errno(name: &'static str, written: &str, span: Span) -> TokenStream`.
- Produces `constlit::linux`:
  - `Errno(i32)`, with `number()`, `name()`, `from_number(i32) -> Option<Errno>`, `Display`, and the derives as `Signal`;
  - the hidden `__errnos` table module: `SUPPORTED`, plus one `Option<i32>` constant per name.
- Families (`cfg`), all Linux or Android:
  - powerpc: `target_arch` `powerpc` or `powerpc64`;
  - mips: `mips`, `mips64`, `mips32r6` or `mips64r6`;
  - sparc: `sparc` or `sparc64`;
  - generic: everything else.
  - Any other OS is unsupported.

**Error messages:**

| `"ENOENTT"` | `unknown errno "ENOENTT"; did you mean "ENOENT"?` |

| unsupported target | `errno! supports Linux and Android` |
